# Plano: Configurar Login no Supabase

## Objetivo
Criar conta de usuário no Supabase via Dashboard para habilitar login no SinistroFacil.

## Credenciais
- **Email**: admin@sinistrofacil.com
- **Senha**: Definir pelo usuário no Dashboard

## Passos Manuais no Supabase Dashboard

### Acessar o Dashboard
1. Abrir `https://acompanhamento-sinistro-supabase-sinistro.lakj7q.easypanel.host`
2. Fazer login com as credenciais de administrador do Supabase

### Criar Usuário
1. No menu lateral, ir em **Authentication** > **Users**
2. Clicar em **"Add user"** ou **"Invite user"**
3. Preencher:
   - **Email**: `admin@sinistrofacil.com`
   - **Senha**: Escolher uma senha forte (mínimo 8 caracteres)
4. Clicar em **"Create user"** ou **"Send invite"**

### Habilitar Login (se necessário)
1. Ir em **Authentication** > **Providers**
2. Verificar se **Email** está habilitado
3. Se "Confirm email" estiver ativo, considerar desabilitar para testes

### Executar RLS Policies
1. Ir em **SQL Editor** no Dashboard
2. Colar e executar o conteúdo de `supabase/rls-policies.sql`

## Verificação
1. Acessar `http://localhost:3000/login`
2. Fazer login com `admin@sinistrofacil.com` + senha definida
3. Verificar redirecionamento para dashboard
4. Verificar header com email e botão logout
