# Plano: RCF - Terceiros Envolvidos no Sinistro

## Contexto
O usuário precisa cadastrar terceiros envolvidos em um sinistro (RCF - Reserva de Cobertura de Terceiros). Cada sinistro pode ter N terceiros. Cada terceiro tem dados pessoais e dados do veículo envolvido. É preciso navegar entre sinistro ↔ terceiro.

---

## 1. Tipos (`src/types/claim.ts`)

Adicionar interface `RCF` e incluir `rcfs: RCF[]` na interface `Claim`:

```ts
export interface RCF {
  id: string;

  // Dados pessoais do terceiro
  name: string;
  cpf: string;
  phone: string;
  email: string;
  // Dados do veículo do terceiro
  vehiclePlate: string;
  vehicleBrand: string;
  vehicleModel: string;
  vehicleYear: string;
  vehicleColor: string;
  vehicleChassis: string;
  vehicleRenavam: string;
  // Dados da apólice do terceiro
  insuranceCompany: string;
  policyNumber: string;
  // Metadados
  createdAt: string;
}
```

## 3. Hook (`src/hooks/use-claims.ts`)

Adicionar 3 funções ao hook `useClaims()`:

- **`fetchRCFs(claimId)`** → busca todos os RCFs de um sinistro
- **`saveRCF(rcf)`** → insere um RCF no Supabase e retorna o registro
- **`deleteRCF(id)`** → remove um RCF

O hook retornará também `rcfs` (state) e as funções acima. Os RCFs serão carregados junto com o claim no `fetchClaims()`.

## 4. Formulário - Etapa 2 (`src/app/novo/new-claim-form.tsx`)

### 4a. Botão "Registrar RCF"
- Inserir botão "Registrar RCF (Terceiros)" antes do "Próximo Passo", visível apenas quando `type === 'Automóvel'`
- Ao clicar, abre um **Dialog** com formulário de cadastro do RCF

### 4b. Dialog de cadastro de RCF
Campos do formulário dentro do Dialog:
- **Dados Pessoais:** Nome, CPF (com máscara), Telefone, E-mail
- **Dados do Veículo:** Placa, Marca, Modelo, Ano, Cor, Chassi, RENAVAM
- **Dados da Apólice:** Seguradora (select igual ao do segurado), Número da Apólice

Botões: "Cancelar" e "Salvar RCF"

### 4c. Lista de RCFs cadastrados
- Abaixo do botão, exibir cards resumidos dos RCFs já cadastrados (nome + placa + botão remover)
- Os RCFs ficam em state local (`localRCFs`) durante o cadastro e são salvos todos de uma vez no `onSubmit`
